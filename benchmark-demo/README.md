# Benchmark / Demo

This directory contains a small synthetic benchmark/demo set for validating behavior without exposing private manuscript text.

## Files

- `cases.md`: benchmark case definitions
- `results.md`: expected behavior notes and sample before/after demonstrations

## Coverage

- low-risk de-templating
- detail-preserving compression
- citation-sensitive compression
- symbol-safe high-risk micro-edits
- surface hygiene cleanup
- claim calibration comparison
- no-op behavior on already-natural prose
- mismatch handling

This package is intended as a release artifact for explanation and regression checking, not as a complete academic-writing benchmark.
