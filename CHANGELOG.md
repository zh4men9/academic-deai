# Changelog

All notable changes to `academic-deai` should be documented here.

## v3

- made `balanced` the default claim mode
- added `Detail Preservation Guard`
- added `Residual Scan`
- formalized transparent reporting with three residual-risk buckets
- added `Surface Hygiene` for deterministic low-risk cleanup
- strengthened citation-sensitive compression rules
- strengthened symbol-safe and high-risk micro-edit behavior

- introduced `No-op`, `Micro-edit only`, and `Full safe rewrite`
- added `Manual Check Items`

- improved whole-manuscript operating discipline

## v1

- established the initial academic-safe de-AI workflow
- defined diagnosis-first conservative rewriting
- protected technical meaning, citation intent, and scholarly tone
- set initial section-aware boundaries
