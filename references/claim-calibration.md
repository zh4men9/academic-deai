# Claim Calibration

Use one explicit claim mode for results, discussion, and conclusion text.

## Default

- Default mode: `balanced`

## Modes

### closer to source

- Use when the user wants stronger fidelity to the original emphasis
- Keep the author's existing argumentative pressure unless it is clearly unsupported
- Prefer light cleanup over visible claim softening

### balanced

- Use by default
- Reduce obvious inflation, vague praise, and broad generality
- Preserve the author's intended direction and emphasis when the source wording is defensible
- Prefer proportionate cleanup over aggressive softening

### conservative

- Use only when the user explicitly prefers stronger restraint
- Tighten scope and interpretive language more aggressively
- Prefer evaluated-setting language over broader implications when support is uncertain

## Decision Rule

When uncertain:

1. preserve meaning
2. preserve evidence linkage
3. preserve concrete detail
4. apply the selected claim mode
5. prefer the less invasive rewrite

## Escalation

If two plausible rewrites would materially differ in claim pressure, either:

- choose `Micro-edit only`, or
- surface the change in `Manual Check Items`
